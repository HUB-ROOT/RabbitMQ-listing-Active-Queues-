# 🐇 RabbitMQ Queue Monitor

A lightweight C# Windows Forms application that connects to the RabbitMQ Management API and displays a real-time list of active queues with pending messages.

## 📌 Features

- 🔗 Connects to RabbitMQ Management HTTP API  
- 📋 Lists all queues with message counts  
- 🔍 Filters and shows only active queues (with pending messages)  
- 🔄 Auto-refreshes every 5 seconds  
- 💻 Simple and clean WinForms UI  
- 🛠️ Easily customizable and extendable

## 🚀 Technologies Used

- C# (.NET Framework or .NET Core)
- Windows Forms
- RabbitMQ HTTP API
- Newtonsoft.Json
- System.Net.Http

## 🛠️ Requirements

- RabbitMQ with Management Plugin enabled  
- Visual Studio or compatible IDE  
- .NET Framework or .NET Core runtime
